# 魔法 × GT：阶段门槛、工业量产与源质守恒

> 2026-11-04 第四批修订。总原则适用于神秘、植物魔法、星辉等所有魔法与GT联动，不只是一份源质换算表。具体电路见 [THAUMIC_CIRCUITS.md](THAUMIC_CIRCUITS.md)，当前验证进度见 [PHASE4_ACCEPTANCE.md](PHASE4_ACCEPTANCE.md)。

## 1. 总原则

**前期用原生魔法玩法建立基础；后期通过有门槛的工业设备、批量生产或明确的工业替代承担规模需求。**

- 第一件应让玩家学习研究、祭坛、魔法材料与原生机制。不要用早期GT配方直接删除这一段体验。
- 到几千几万件时，不应继续要求玩家重复手搓、刷不可控Boss掉落或一次次站在祭坛旁。解锁机器/研究后，让资源、能量、空间和物流成为主要限制。
- 自动化不等于免费：保留实际消耗、重要前置和跨级结构。不能因转换器漏中心物、把重复符号只算一次、把不认识的材料跳过而便宜。
- 对宝珠、特殊掉落等不能常规再生产的消耗品，必须给出晚期可再生产替代，或将其明确定义为一次性解锁，而不是暗中要求无限刷取。
- 只做审过的白名单；不能把所有魔法配方一键转工业，包括附魔、法杖组装和活体注魔。

## 2. 阶段与边界

| 阶段 | 玩家必须完成 | 提供的能力 | 不得绕过 |
|---|---|---|---|
| 前期魔法 | 原生研究、工作台、坩埚、注魔等 | 首件材料和模板 | 原生魔法内容与资源获取 |
| 中期电路联动 | 同级PCB、线材、焊料、机器及洁净室 | 魔法元件作为芯片/贴片的并行来源 | 电路等级、科技材料与环境门槛 |
| LuV附近工业注魔 | 控制器和结构、源质流体供应、机主研究 | 四模板及白名单材料量产、珍珠晚期替代 | 生物线、研究、真实材料与能源支付 |
| ZPM/UV规模化 | 低一级电路、湿件PCB、研究站/装配线 | 并行、超频、多台设备及自动物流 | 递归电路成本、装配线研究 |

本包主体到UV，少量UHV选修；UEV～MAX不是本次联动的扩展目标。

## 4. 三种计量与换算

| 计量 | 用途 | 工业转换 |
|---|---|---|
| 源质 essentia（点） | 注魔、炼金、转换矩阵 | 1点 → 144mB对应要素流体 |
| 要素流体（mB） | Pollution/GT机器 | 不能再次乘144；方法明确接收mB |
| 奥术vis（点） | 法杖/奥术工作台六原始通道 | 1点 → 36mB对应原始流体 |

vis只接受 `aer/ignis/aqua/terra/ordo/perditio`；复合要素不能写入vis。36mB是整合包工业转换规则，不声称它是TC本体的通用vis↔essentia交换率。

六原始要素物品闭环以第一批规则为基准：1点=144mB=1份指定元素粉/宝石。此结论不能外推到所有复合要素、附属材料、任意加工路径。

高压釜返造已改为Pollution自身元素宝石，不返造可拆出多碎片的TC晶簇；原生TC晶簇玩法不删。

## 5. 要素表与守恒审计

正确资源路径：`data/<自己的modid>/thaumcraft/object_aspects/*.json`。TC本体是 `data/thaumcraft/thaumcraft/object_aspects/`；Pollution是 `data/pollution/thaumcraft/object_aspects/`。少一层目录可能静默不加载。

Forge 1.20.1 条件：`{"type":"forge:mod_loaded","modid":"gtnn"}`，不是NeoForge条件格式。

第三批使用单主导要素和材料份额缩放，并显式写空表防止错误推算。**这是降低错误估值的办法，不是全包守恒证明。**

旧报告记录4,118→2,883个flag，并声称剩余9条有值输入为有界放大。这些是旧测试环境的审计结论；第四批尚未逐条复现，不再写成“全包无可重复闭环”。正确验收方式：

1. 导出当前完整服物品估值、流体映射和最终配方。
2. 分别核对可逆的粉/粒/锭/板/块/宝石梯，计算物质份额与各要素当量。
3. 将单条放大与完整循环分开；每条例外记录原料、产物、消耗、回路及边界。
4. 未解决的flag保留为未验/缺陷，不以“有界可接受”替代平衡决策。

## 6. 源质炉与批处理记账

`本次生成总量 = 已成功送出量 + 待送剩余量`。

- 按实际接收量扣减，不向多个接收器重复发整批。
- GT流体按mB保存，17mB等余数不截断。
- 满罐保留pending，不重复消费输入/燃料。
- 结构失效暂停，保存/恢复批次。

## 7. 新联动检查清单

- [ ] 所有ID在实际整合包存在，原生制作链真实可达。
- [ ] 第一件的魔法体验、研究门槛保留；量产解锁阶段明确。
- [ ] 重要科技前置、递归部件、同级电压/机器/洁净室/研究没有被绕过。
- [ ] 材料数量包含有序配方重复格、注魔中心物和每个基座；不可识别输入整条拒绝。
- [ ] NBT、动态产物、保留工具、输入变换等特殊语义不被无条件扁平化。
- [ ] 源质/vis换算只一次，零负值/溢出受控，往返循环已核对。
- [ ] 不可再生产的消耗品有合理晚期替代；原始珍珠不能变成每板必刷Boss。
- [ ] 研究、缺材料、低电压、无洁净室等负例实际拒绝。
- [ ] 批量执行/并行后真实扣料、耗能、产出与停机保存正确。
- [ ] 任务生成器、文档、jar版本、差分包和镜像同步；测试与部署证据不混写。

## 8. 不应采取的捷径

不要凭编译成功/JEI可见就宣称可制造；不要把KubeJS回退提示直接等同原版配方丢失；不要用关闭功能、无限供应、静默跳输入或提高起始等级掩盖坏调用链。明确标出测试环境差异和未覆盖行为。
