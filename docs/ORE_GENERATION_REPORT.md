## 7. 异常与待核实

### 7.1 KubeJS 注册矿脉的 cluster_size 全为 0（已修复）

- 现象：KubeJS 注册的 46 条矿脉 cluster_size 全为 0-0；`gtceu:*` 等 Java/addon 矿脉正常。
- 根因：KubeJS 给 `net.minecraft.util.valueproviders.IntProvider` 注册了 TypeWrapper（`UtilsJS.intProviderOf`），只识别 Number / List / Map；传入已是 `UniformInt` 的 Java 对象时返回 null，Rhino 遂按 `clusterSize(int)` 重载解析成 0。
- 修复：`oreVeins.js` / `tfHvOreVeins.js` 改为 `vein.clusterSize([v.size[0], v.size[1]])`（JS 数组 → `UniformInt`）。2026-11-15 DEV 实测：46 条全部恢复为 `UniformInt`（如 `kubejs:tf_lapis_vein` 40-52）。

### 7.2 Forge biome modifier 有 1 条解析失败
