# 怎么游玩 Society · Sunlit Valley 服务器

> 本教程针对 **Society · Sunlit Valley**（Minecraft 1.20.1 / Forge 47.4）整合包。
> 第一次进服按 1 → 5 步做完即可，全程大约 20 分钟。

---

## 0. 先确认你的电脑够用

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11 64 位，或 macOS 11 以上（Intel、Apple 芯片都行） |
| Java | **Java 21**（17 也能跑，21 更稳） |
| 内存 | 16 GB 以上（整合包要分 8 GB 给游戏） |
| 硬盘 | 至少 15 GB 空闲 |
| 网络 | **国内建议全程挂梯子**，更新走的是 GitHub |

---

## 1. 安装 Java 21

先看看有没有装。打开「命令提示符 / 终端」，输入：

```
java -version
```

看到 `17.x` 或 `21.x` 就说明有，跳到第 2 步。没有（或者提示"不是内部或外部命令"）就下载：

**https://learn.microsoft.com/zh-cn/java/openjdk/download**

- Windows：下 **x64 Windows .msi**
- macOS（Apple 芯片 M1/M2/M3/M4）：下 **macOS / aarch64 .pkg**
- macOS（Intel）：下 **macOS / x64 .pkg**

一路下一步装完，**重开一个终端**再敲一次 `java -version` 确认。

> 别装 Java 8 / 11，游戏起不来。

---

## 2. 下载并解压整合包

在**群文件**里下载最新的 `Society-Sunlit-Valley-1.20.1.zip`，解压到一个**没有中文、没有空格**的路径，例如：

```
D:\Games\SunlitValley\
```

> 别放在 `C:\Program Files`、桌面或下载文件夹里 —— 权限和中文路径都可能出问题。

解压完的目录应该长这样（**更新脚本就在启动器旁边**）：

```
SunlitValley\
├─ HMCL-3.10.0.318.jar        启动器
├─ 更新.bat                    Windows 手动更新（双击运行）
├─ 更新.command                macOS 手动更新（双击运行）
├─ ModpackUpdater-all.jar      更新器本体
├─ 启动说明.txt
└─ .minecraft\                 游戏本体 + 整合包内容
```

---

## 3. 用 HMCL 启动器打开

**Windows**：双击 `HMCL-3.10.0.318.jar`
（双击没反应就在文件夹里按住 Shift + 右键 → 「在此处打开 PowerShell 窗口」→ 输入 `java -jar HMCL-3.10.0.318.jar`）

**macOS**：终端 `cd` 到该文件夹，执行 `java -jar HMCL-3.10.0.318.jar`
（第一次打开如果提示"无法验证开发者"，去 系统设置 → 隐私与安全性 → 点「仍要打开」）

启动器打开后做三件事：

1. 左侧「游戏目录」确认指向本文件夹里的 `.minecraft`
   （`hmcl.json` 已经预置好，一般不用改；不对的话手动选一下）
2. 版本列表里选中 **Society Sunlit Valley**
3. 进「设置 → 全局游戏设置 → 内存」，**至少 8192 MB**
   （16 GB 内存给 8192，32 GB 可以给 10240）

---

## 4. 外置登录（这步不做进不去服务器）

服务器已经开了**外置登录**（Yggdrasil 协议，authlib-injector 注入）。意思是：

- ❌ **不能用「离线登录」**，离线账号进服会被直接踢掉
- ✅ 必须用一个 Yggdrasil 账号，本服推荐用 **LittleSkin**（免费，顺便管皮肤）

### 4.1 注册 LittleSkin 并建角色

**https://littleskin.cn/auth/register**

注册 → 进后台 → **角色管理 → 添加角色**。
角色名就是游戏里显示的名字，**推荐全英文 + 下划线**（也支持中文）。

### 4.2 在 HMCL 里添加外置账户

1. 打开 HMCL → **账户列表** → 右上角 **添加账户**
2. 账户类型选 **「外置登录（authlib-injector）」**
3. 认证服务器地址填：

```
https://littleskin.cn/api/yggdrasil
```

> 如果群公告给了别的认证地址，**以群公告为准**。

4. 用 LittleSkin 的**邮箱 + 密码**登录，成功后左侧会显示你的角色名

> 第一次登录时 HMCL 会自动下载 authlib-injector，等它下完再点启动。

---

## 5. 进服务器

1. 点「启动」。**第一次启动**会下载原版资源文件（约 1.1 GB，启动器已默认用 BMCLAPI 镜像，保持网络通畅）
2. 进主菜单 → **多人游戏** → **添加服务器**
3. 地址填：

```
dx.frp-cat.com:62618
```

4. 双击进服

> 进服前先确认整合包是最新的（下一节），版本不一致会被踢。

---

## 6. 更新整合包（很重要）

服务器会跟着整合包一起更新，**版本对不上就进不去**。

### 6.1 自动更新（启动器开着就会跑）

如果启动时先弹出一个小窗口显示进度条 —— 说明自动更新是开着的：

- 等它跑完，窗口自己关掉，然后进游戏
- 没有更新内容时一闪而过
- 更新器**只动整合包自己的文件**：你的存档、自己加的 mod、自己改的配置都不会被碰

### 6.2 手动更新（自动更新失败 / 没弹窗时）

**双击根目录里的脚本**（和启动器同级）：

| 系统 | 双击 | 说明 |
| --- | --- | --- |
| Windows | `更新.bat` | 黑窗口跑完会停 8 秒 |
| macOS | `更新.command` | 第一次要先在终端 `chmod +x 更新.command` |

脚本做三件事：

1. **找 Java**：`JAVA_HOME` → PATH → 整合包自带的 JRE，挨个找
2. **找更新器**：根目录的 `ModpackUpdater-all.jar`，或 `.minecraft/versions/Society Sunlit Valley/` 里的
3. **跑增量更新**：`--target .minecraft`，按 SHA-256 比对，只下变化的文件

看到「**更新完成**」再回 HMCL 启动。失败会停在窗口里告诉你原因。

### 6.3 国内必须挂梯子

更新源是 **GitHub**：

```
https://raw.githubusercontent.com/MineRealms/UpdateRepo/main/manifest.json
```

国内直连基本是**超时 / 连接被重置 / 下载 0 速度**。所以：

- 开 **Clash / v2rayN / Surge** 之类的代理，**打开「系统代理」或 TUN 模式**
- 更新器会自己读系统代理（Windows 读注册表，macOS 读 `scutil --proxy`），**不用给 Java 单独配代理**
- 更新完可以关掉梯子再玩游戏（游戏本身直连服务器）

### 6.4 更新失败怎么排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `PKIX path validation failed` / `validity check failed` | 系统时间不对，或代理劫持了证书 | 校准系统时间（设置 → 时间和语言 → 立即同步）；换个代理节点 |
| 一直 0% / 卡住不动 | GitHub 连不上 | 挂梯子，换节点 |
| 下到一半断了 | 网络抖动 | 再双击一次，已下好的不会重下 |
| 杀软报毒 | 更新器是自签程序 | 加白名单；或用 `更新.bat`（jar 版，不走 exe） |

日志位置（反馈问题时把最新的那份发出来）：

- Windows：`%USERPROFILE%\.modpackupdater\logs\`
- macOS：`~/.modpackupdater/logs/`

### 6.5 实在更新不了

找管理员要**最新的完整整合包**，解压覆盖到同一目录即可（存档在 `.minecraft/saves`，覆盖不会丢，但保险起见先备份）。

## 8. 常见问题

**Q：进服提示「无效的会话」/「未验证的用户名」**
A：没用外置登录账号。回第 4 步重加账户，别选离线登录。

**Q：提示 mod 不匹配 / 缺少 mod / 被服务器踢**
A：整合包不是最新版，先做第 6 节的更新。

**Q：卡顿、内存溢出、闪退**
A：内存至少分 8192 MB；关掉光影；把渲染距离降到 8～10。

**Q：启动器打不开 / 双击没反应**
A：Java 没装好，或装成了 32 位。重装 Java 21 再试。

**Q：macOS 提示「无法打开，因为无法验证开发者」**
A：右键 → 打开 → 仍要打开；或去 系统设置 → 隐私与安全性 里点「仍要打开」。

**Q：更新完游戏进不去 / 版本号对不上**
A：先跑一次 `更新.bat`，再启动；还不行就在 HMCL 里删掉版本重新解压。
